# tablelog. — 테이블로그

친구들과 함께 쓰는 보드게임 리더보드. Next.js App Router + TypeScript + MongoDB로 구현한 Vercel 배포용 프로젝트입니다.

## 시작하기

Node.js 20.9 이상을 사용하세요.

```bash
npm ci
npm run dev
```

http://localhost:3000 에서 열립니다. MongoDB 설정이 없으면 **데모 모드**로 실행됩니다. 데모의 샘플 기록과 변경 사항은 해당 브라우저의 localStorage에만 저장되며 다른 사용자와 공유되지 않습니다. 데이터베이스 연결 실패를 데모 모드로 숨기지 않고 오류를 표시합니다.

## Vercel 배포

1. 이 폴더를 GitHub 저장소에 올립니다. `.env.local` 등 비밀 정보는 커밋하지 마세요.
2. MongoDB Atlas에 클러스터와 읽기/쓰기 권한이 있는 DB 사용자를 생성합니다. Atlas의 네트워크 접근 설정에서 배포 서버의 접속을 허용하세요. 고정 egress IP가 없는 환경에서는 Atlas/Vercel 네트워킹 옵션을 확인하세요.
3. Vercel에서 저장소를 Import하고 프레임워크를 **Next.js**로 선택합니다. 별도 빌드/출력 설정은 필요 없습니다. 프로젝트를 하위 폴더에 넣었다면 Root Directory를 이 폴더로 지정하세요.
4. Vercel 환경변수를 설정합니다.

| 변수 | 용도 |
|---|---|
| `MONGODB_URI` | Atlas 연결 문자열. 비밀번호의 특수문자는 URL 인코딩 필요 |
| `MONGODB_DB` | DB 이름. 기본값 `tablelog` |
| `BGG_API_TOKEN` | 선택 사항. BGG 전체 게임 검색용 서버 토큰 |

5. Deploy합니다. 환경변수를 변경했다면 Redeploy합니다.
6. 새 DB는 빈 테이블로 시작합니다. 게임과 플레이어를 추가하고 첫 기록을 남기세요. 샘플 데이터는 실제 DB에 자동 삽입되지 않습니다.

로컬에서 DB에 연결할 때는 `.env.example`을 `.env.local`로 복사하고 값을 입력하세요. 토큰과 DB 연결 문자열은 서버에서만 읽습니다.

## 기능

- 대시보드: 플레이 횟수, 게임 수, 참가자 수, 누적 시간, 최근 기록, 최근 6개월 차트
- 라이브러리: 기본 게임, BGG 전체 검색, 수동 등록, 게임별 점수 규칙
- 플레이 기록: 날짜/시간/참가자/점수/메모, 수정 및 삭제
- 리더보드: 전체 승수 순위, 게임별 개인 최고 점수 순위, 승률/평균 점수
- 통계: 기간 필터, 월별 플레이, 게임별 플레이 분포
- 플레이어: 이름과 프로필 색상 등록
- 모바일/태블릿 대응, 키보드 모달 조작, 저장 오류 표시

로그인과 권한 구분이 없는 공개 편집 방식입니다. 사이트를 방문한 누구나 공유 데이터를 추가하고 플레이 기록을 수정·삭제할 수 있습니다. 게임과 플레이어 삭제 기능은 기록의 참조 무결성을 위해 제공하지 않습니다. 플레이 기록은 낙관적 잠금을 사용하여 다른 사용자의 최신 수정을 덮어쓰지 않습니다. 공동 우승자는 각각 1승으로 계산합니다. 전체 순위는 승수 → 승률 → 플레이 수, 게임별 순위는 최고 점수 → 승률 기준입니다. 승리 횟수/승률은 게임별로 합산하며 서로 다른 게임의 점수를 합산하지 않습니다.

점수 기반 경쟁 게임에 맞춰져 있습니다. 협동 게임/팀 점수는 별도 구현이 필요합니다. 게임 등록 이후 점수 규칙은 고정됩니다. 플레이 횟수는 세션 수, 플레이 시간은 세션 시간의 합계이며 인원 수를 곱하지 않습니다. 날짜는 사용자가 입력한 현지 달력 날짜로 저장합니다.

## BoardGameGeek

공식 안내: https://boardgamegeek.com/using_the_xml_api

BGG의 승인된 애플리케이션 토큰을 `BGG_API_TOKEN`에 넣으면 서버에서 XML API2의 search/thing을 호출합니다. 토큰이 없거나 BGG가 응답하지 않으면 기본 목록과 직접 등록을 사용할 수 있습니다. 한글 검색 결과가 적으면 영문명을 사용하세요. BGG는 게임 메타데이터만 제공하며 점수 규칙은 등록할 때 직접 선택합니다. 검색 결과는 최대 12개이며 서버에서 24시간 캐시합니다. BGG 사용 조건과 attribution 요구사항은 애플리케이션 등록 시 확인하세요.

게임 카드는 자체 SVG 일러스트를 사용하며 공식 박스 아트가 아닙니다. BGG 원본 링크는 해당 게임 리더보드에 표시합니다. 폰트는 Google Fonts의 DM Sans / Noto Sans KR이며 네트워크 없이도 시스템 폰트로 표시됩니다.

## 데이터 구조

`games`, `players`, `plays` 세 컬렉션에 저장합니다. 각 문서의 문자열 `id`를 MongoDB `_id`로도 사용해 중복 ID를 방지합니다. 점수 기록은 플레이어 ID와 게임 ID를 참조합니다. DB 연결은 서버 인스턴스에서 재사용합니다. 실제 데이터는 브라우저에 저장하지 않으며 페이지 새로고침으로 다른 친구의 최신 기록을 불러옵니다.
